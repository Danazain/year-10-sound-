Mission briefing · 3 minutes

How does a computer store sound?

Sound begins as a continuous analogue wave. An analogue-to-digital converter (ADC) measures the wave at regular intervals. Each measurement is represented using binary digits.

Sample rate

How many measurements are taken every second, measured in hertz (Hz).

Bit depth

How many bits are used to represent each measurement.

Trade-off

More samples or bits can improve accuracy but make uncompressed files larger.

Experiment 2 · 7 minutes

🧮 Sound file-size calculator

For uncompressed mono audio, calculate:

File size (bits) = sample rate × bit depth × duration

Try the example from the slides: 6 Hz × 4 bits × 3 seconds. Then double the sample rate. Does the file size double?

For stereo audio, multiply by 2 channels. This calculator assumes one channel and no file headers or compression.
